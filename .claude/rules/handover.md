# 인수인계 규칙
- 마트 작업(builder)에만 적용. 하네스 개발 PR은 PR 본문의 요약·결정·검증으로 갈음
- 마트의 모든 작업이 통과하면 scripts/handover/ 를 실행해 .dev/handover/<브랜치>.md 초안을 만든다.
- 사실 부분(바뀐 것, 데이터 흐름, 검증 결과, 반려 이력, 링크)은 스크립트 출력을 그대로 둔다. 고치거나 추측해서 채우지 않는다.
- 설명 부분(한 줄 요약, 운영 방법, 주의점)만 작성한다. 처음 보는 데이터 엔지니어가 읽고 재실행·장애 대응을 할 수 있게 쓴다.
- docs/handover/ 는 직접 수정하지 않는다. PR 결재 후 사람이 반영한다.
- 초안이 없으면 작업은 완료가 아니다.
